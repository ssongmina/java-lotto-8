# java-lotto-precourse

## 입력
***
- `구입금액을 입력해 주세요.`
- `당첨 번호를 입력해 주세요.`
- `보너스 번호를 입력해 주세요.`

## 입력 검증
***
- 구입 금액과 보너스 번호 입력 시, 해당 입력이 숫자가 맞는지 확인 필요
- 당첨 번호를 입력 시, 6개의 숫자가 맞는지, 각 숫자 간에 쉼표로 구분되어 있는지, 숫자가 중복되지 않는지 확인 필요

## 구매한 로또 번호 생성
***
- 로또 생성 시, 1부터 45까지의 숫자 중 랜덤으로 6개의 숫자를 추첨한다

## 당첨 통계
***
- 발행한 로또에 대해서 당첨 번호와 일치하는 개수를 카운트하고, 기록한다.
- 수익률 계산도 실시한다.


## 출력
***
- 구매한 로또 개수와 해당 로또들의 번호들을 출력한다
- 당첨 통계 내용을 출력한다
- 수익률을 출력한다.
